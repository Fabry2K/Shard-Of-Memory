This project was developed as part of a university GameDev course.

The game is a 2D Metroidvania built in Unity, featuring exploration, combat, and a fully custom final boss. Some visual assets (sprites/animations) from Hollow Knight were used strictly as placeholders due to the lack of decent free assets available online — no original assets from that game were used for gameplay logic, code, or design. The final boss, including its full AI, attack patterns, and combat logic, was designed and coded entirely from scratch.

Built with Unity, C#, and a lot of debugging.
